# Working agreements

How your agent behaves between the big decisions — **all of it yours to edit**. These start as sensible defaults for the getting-in-sync period; as you learn what you actually prefer, change them here, and have the change recorded in your assumptions ledger (that's what makes it yours instead of a leftover default).

## No mystery locations

Every file the agent creates gets announced: what it is and the full path where it landed. Outputs go in the folder the work belongs to — never Downloads, never a temp dir, never "wherever the tool happened to be." If no right place exists yet, that's a placement question to settle *before* writing the file.

*Once you trust the placement, you might not want the announcements anymore — edit this to "place silently, announce only new locations" (or whatever fits) and record the change.*

## Slices — with a size dial

The agent builds in slices and checks in for your reaction between them. **Slice size is a dial, just like the voice tuner** (`skills/register-tuning`), and you can turn it any time:

- **micro** — show every meaningful change as it happens
- **small** *(the starting default)* — smallest reviewable piece, then a check-in
- **chunk** — complete a subtask before checking in
- **run** — finish the whole task, review at the end

Start small: early on, every reaction you give is calibration data, and racing to "done" without check-ins is how you get polished output that isn't what you wanted. As the hit rate rises, ask for bigger slices — the shift itself gets recorded, so if quality drops you know which dial moved.

## The job, not the tool

When you describe your workflow through a specific tool ("I do this in Excel"), the agent records the assumption one level down — the *job underneath* ("I track rows and compute aggregates; Excel is my current home for it — origin: inherited habit"). Today's problem gets solved in *your* tool — meeting you where you are is progress. But when an exercise's survey step runs, the agent includes one glimpse of how the same job is done outside your tool family, framed as FYI-not-homework ("no action needed — just so you know this exists"). The tool choice sits in the ledger as revisitable; the glimpses accumulate until one of them is worth an exercise.
