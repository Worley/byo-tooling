# Awesome UI


Everything that helps build and present material beautifully. Each entry was retrieved and its licence read off the source, because these are dependencies you may ship: a NonCommercial or source-available licence is a fact you need before you adopt, not after.

**How this list was built.** Each section was produced by an automated research pipeline and passed a verification gate before landing here: every URL fetched in-run, every tag supported by quoted on-page evidence, and a proof-of-fetch check that a status code alone cannot satisfy. Sections that could not clear that gate are not here — see Coverage gaps.

## Component Systems & Headless Primitives

- [shadcn/ui](https://github.com/shadcn-ui/ui) — Distributes ready-to-copy components sourced from Radix UI (headless primitives) and Tailwind CSS (styling). Run `npx shadcn add <component>` to pull a single component into your project; no monolithic dependency.
- [Radix Primitives](https://github.com/radix-ui/primitives) — Provides fully accessible, keyboard-navigable headless React primitives (Dialog, Select, Popover, Tabs, Combobox, Menu, etc.) with no styling opinion. ARIA correctness is the sole concern.
- [daisyUI](https://github.com/saadeghi/daisyui) — A Tailwind CSS plugin that adds named component classes (`btn`, `card`, `modal`, `dropdown`, `navbar`, etc.) on top of Tailwind utilities. Zero JavaScript — purely CSS classes.
- [@adobe/react](https://github.com/adobe/react-spectrum) — A comprehensive, adaptive React component library with built-in accessibility (WCAG 2.1 AA), internationalisation, and design tokens. Covers everything from buttons and form fields to complex data grids and date pickers.
- [Headless UI](https://github.com/tailwindlabs/headlessui) — Officially-maintained by the Tailwind CSS team, Headless UI provides unstyled, fully-accessible React and Vue components (Dialog, Menu, Transition, Switch, Combobox, Listbox). No CSS shipped — zero dependency chain.
- [Mantine](https://github.com/mantinedev/mantine) — A React component library with 100+ components and 60+ hooks. Includes built-in theme provider, form validation, notifications, modals, date pickers, and more. Ships pre-styled but highly customizable.
- [Ariakit](https://github.com/ariakit/ariakit) — A headless library providing accessible primitives (Combobox, Select, Dialog, Tabs, Hovercard, Command) with a focus on ergonomics and composability. Ships with opinionated styling but can be fully stripped to CSS-in-JS or Tailwind.
- [MUI (Material UI)](https://github.com/mui/material-ui) — The most popular React UI library. Provides a comprehensive set of accessible, Material Design–compliant components (buttons, dialogs, tables, forms) with extensive customization and theming.
- [HeroUI](https://github.com/heroui-inc/heroui) — A modern React component library built with Tailwind CSS and Radix UI primitives. Provides buttons, cards, inputs, modals, and more with built-in theming support and dark mode. Forked from Vercel UI; formerly known as NextUI.
- [Chakra UI](https://github.com/chakra-ui/chakra-ui) — A modular, accessible React component library with a powerful styling system. Uses a token-based theme approach with props for theming (colorScheme, size, variant). Includes components for layout, feedback, data display, and forms.
## CSS, Styling & Design Tokens

- [Tailwind CSS](https://github.com/tailwindlabs/tailwindcss) — The dominant utility-first CSS framework for rapid UI development. Native React/Astro support via `@tailwindcss/vite` plugin; the v4 rewrite is CSS-first (config moves to CSS via `@theme` blocks), making it fully compatible with the consumer stack. Produces highly readable, consistent layouts with purpose-built spacing, color, and typography utilities that help content present itself clearly. **(MIT · framework)**
- [UnoCSS](https://github.com/unocss/unocss) — The instant on-demand atomic CSS engine. Works as a drop-in replacement for Tailwind with built-in presets and a flexible config. Framework-agnostic (supports Astro, React, Svelte, Solid). 5× faster than Windi CSS, zero deps, and 6kb min+brotli. Great alternative when Tailwind's utility set doesn't match your design language — lets you define custom atomic classes that produce clean, minimal CSS output for fast-rendering pages. **(MIT · framework)**
- [Panda CSS](https://github.com/chakra-ui/panda) — Universal, type-safe, CSS-in-JS framework for design systems. Built by the Chakra UI team with its own config-driven approach. Supports React, Vue, Svelte, and Solid. Build-time type safety ensures style changes propagate consistently across the entire UI, preventing visual regression. CSS-first with cascade layers (`@layer`) and CSS variables for theming — modern, scoped, and scalable. **(MIT · framework)**
- [vanilla-extract](https://github.com/vanilla-extract-css/vanilla-extract) — TypeScript-first, zero-runtime Stylesheets-in-TypeScript. A compiler that generates static CSS files at build time — no runtime overhead, no browser compatibility concerns. Locally scoped class names and CSS Variables with a high-level theme system supporting simultaneous themes. Works perfectly with Astro and React, generating CSS at build time. Enables type-safe design tokens that keep visual consistency across components while preventing typos that cause visual bugs. **(MIT · framework)**
- [clsx](https://github.com/lukeed/clsx) — Tiny (239B) utility for constructing `className` strings conditionally. The go-to for conditional class composition in React: `className={clsx(isActive && 'highlighted')}`. Enables clean conditional styling for hover states, active states, disabled states, and responsive variants — all of which are fundamental to interactive UI presentation. 3× faster and 50% smaller than the older `classnames` module. Essential for any Tailwind-based React project. **(MIT · library)**
- [tailwind-merge](https://github.com/dcastil/tailwind-merge) — Utility function to efficiently merge Tailwind CSS classes in JS without style conflicts. The de facto standard for React component libraries — when a component accepts a `className` prop, this resolves all duplicate Tailwind utility conflicts (e.g. conflicting padding, color, or spacing) so the final rendered element always presents the correct visual state. Essential for shadcn/ui components and any dynamic class composition. Supports Tailwind v4.0–v4.3. **(MIT · library)**
- [class-variance-authority (cva)](https://github.com/joe-bell/cva) — Declarative API for building variant-based component styles. Popular in React component libraries (shadcn/ui, Radix UI) for managing prop-driven visual variants such as `variant="outline" size="lg"`. The repo has migrated to `joe-bell/cva` — the old `class-variance-authority/class-variance-authority` is archived. Generates fully type-safe, exhaustive variant definitions that prevent invalid combinations from ever rendering, keeping the UI visually consistent and predictable. **(Apache-2.0 · library)**
- [styled-components](https://github.com/styled-components/styled-components) — Fast, expressive styling for React with server components, client components, streaming SSR, and React Native — one API. Full CSS support including media queries, pseudo-selectors, nesting, keyframes, and global styles. The `<13kB` gzipped size and automatic scoping mean every component carries its own visual identity without leaking styles. Theming via React context lets you switch color palettes, spacing scales, and typography globally — ensuring the entire presentation adapts consistently to user preferences or brand requirements. **(MIT · library)**
- [Emotion](https://github.com/emotion-js/emotion) — High-performance CSS-in-JS library designed for flexible style composition. Supports string or object styles, source maps, and heavy production caching. Used by Netflix, Codecademy, Gatsby, and Sentry. Enables dynamic, data-driven styling where component appearance changes based on props, theme context, or user state — for example, a chart's color palette adapts to dark mode, or a button's hover effect responds to user interaction. Every style is scoped and typed, preventing visual conflicts across the app. **(MIT · library)**
- [Tailwind CSS Typography](https://github.com/tailwindlabs/tailwindcss-typography) — Beautiful typographic defaults for HTML you don't control. The `prose` class transforms any raw HTML (from markdown, CMS, or third-party sources) into publication-quality, readable content. Hand-tuned by professional designers covering font sizes, heading spacing, code block padding, and more. Five size modifiers (`sm` through `2xl`), five gray scales (`gray`, `slate`, `zinc`, `neutral`, `stone`), and dark mode variants. Essential for documentation, blogs, and content-rich pages where the content itself must present itself well without custom typographic CSS. **(MIT · library)**
- [Radix Colors](https://github.com/radix-ui/colors) — A gorgeous, accessible color system used by Radix UI and many component libraries. Pre-built CSS custom properties for accessible color palettes (13 palettes, each with 10 tones). Drop-in with Tailwind v4 via CSS variables or use directly. Helps designers and developers pick color combinations that maintain proper contrast ratios and visual harmony — the foundation for any accessible, visually appealing design system. **(MIT · assets)**
- [Material Design Icons](https://github.com/google/material-design-icons) — Google's official icon set: Material Symbols (current, variable-font based) and Material Icons (classic). Thousands of icons in multiple styles (outlined, filled, rounded, sharp, two-tone) and weights (100–700). Available as SVG sprites, web fonts, and React components via npm packages. Provides a consistent, recognizable visual language with strong accessibility support (screen-reader descriptions, consistent sizing and stroke weights) — every icon is designed so users can instantly understand the meaning and function of UI elements. **(Apache-2.0 · assets)**
- [Style Dictionary](https://github.com/amzn/style-dictionary) — Build tool for creating cross-platform style systems. Amazon's official tool for design tokens. Outputs CSS, iOS, Android, Figma, and more from a single JSON source. Integrates with PostCSS and is compatible with the consumer stack. Ensures that every platform renders the same colors, spacing, typography, and motion — eliminating visual inconsistency between web, mobile, and desktop presentations. Design tokens define the visual language once, and every surface, component, and state uses the same values. **(Apache-2.0 · tool)**
## Data Visualisation

- [d3](https://github.com/d3/d3) — The foundational JavaScript data visualisation library. A low-level toolkit for binding data to DOM elements and creating custom visualisations with SVG, Canvas, or HTML. Extremely powerful and flexible — the building block that many higher-level chart libraries (Recharts, Nivo, visx) depend on internally. (BSD-3-Clause · library)
- [recharts](https://github.com/recharts/recharts) — Redefined chart library built with React and D3. Provides a composable set of chart components (BarChart, LineChart, AreaChart, PieChart, RadarChart, ResponsiveContainer, etc.) with a React-friendly API. Integrates smoothly with shadcn/ui's design philosophy — you can style charts with Tailwind classes. (MIT · component-system)
- [observable](https://github.com/observablehq/plot) — A concise, layered-grammar API for exploratory data visualisation, developed by the Observable team. More declarative than D3 — you describe what to plot and it handles the rendering. Supports a wide variety of chart types through composable encodings. (ISC · library)
- [visx](https://github.com/airbnb/visx) — A low-level visualization component library by Airbnb. Provides composable React primitives for charts (axes, scales, tooltips, axes, shapes, shapes, patterns, paths, gradients) plus higher-level chart types. Built on top of D3 but with a React-first API. (MIT · component-system)
- [apache](https://github.com/apache/echarts) — Apache ECharts — a powerful, interactive charting and data visualisation library for the browser. Supports a massive variety of chart types (maps, 3D, scatter, heatmap, parallel, funnel, gauge, Sankey, flow, sunburst, tree) with GPU-accelerated rendering. (Apache-2.0 · library)
- [chartjs](https://github.com/chartjs/Chart.js) — Simple, flexible HTML5 canvas-based charts. The most popular charting library on npm. Provides basic chart types (line, bar, radar, polar area, doughnut/pie, bubble, scatter, horizontal bar, combo) with a very simple API. (MIT · library)
- [nivo](https://github.com/plouc/nivo) — Rich dataviz components built on D3 and React. Provides beautifully styled chart components (Bar, Line, Area, Scatter, Pie, Donut, Radial, Bubble, Heatmap, Sankey, Network, Calendar, Treemap, Sunburst, CirclePacking, Tableau, Stream, Funnel, Gauge, WordCloud, etc.). (MIT · component-system)
- [vega](https://github.com/vega/vega-lite) — A concise grammar of interactive graphics, built on top of Vega. You specify your data, axes, marks, and encodings — Vega-Lite handles the rest. Can render to SVG, Canvas, or embed in React apps. (BSD-3-Clause · framework)
- [tremor](https://github.com/tremorlabs/tremor) — Copy-and-paste React components for dashboards and data visualisation. Built with Tailwind CSS, shadcn/ui, Radix UI, and Recharts. Provides ready-to-use components (AreaChart, BarChart, LineChart, Metric, DonutChart, Map, Sparkline, StackedBarChart, TrendItem, TrendSparkline, etc.) that match the Tailwind v4 design language. (Apache-2.0 · component-system)
- [uPlot](https://github.com/leeoniya/uPlot) — A small, fast chart library for time series, lines, areas, OHLC and bars. Only ~8kb gzipped. No dependencies. Renders on Canvas or SVG. (MIT · library)
- [plotly.js](https://github.com/plotly/plotly.js) — Open-source JavaScript charting library behind Plotly and Dash. Supports 40+ chart types including 3D surfaces, scientific plots, geospatial maps, and financial charts. Very rich out-of-the-box experience. (MIT · library)
- [highcharts](https://github.com/highcharts/highcharts) — Industry-standard JavaScript charting framework used by over 300,000 companies worldwide. Produces beautiful, interactive charts with extensive documentation. Supports 80+ chart types including stock charts, gauges, maps, and 3D. (Highcharts EULA · paid)
- [vega](https://github.com/vega/vega) — A visualization grammar — a declarative language for creating, saving, and sharing interactive visualisation designs. Lower-level than Vega-Lite; you specify the full pipeline from data to marks, scales, and axes. (BSD-3-Clause · framework)
## Diagrams Illustration

- [Mermaid](https://github.com/mermaid-js/mermaid) — JavaScript-based diagramming and charting tool using Markdown-inspired text definitions. Renders flowcharts, sequence diagrams, class, state, ER, Gantt, pie, mindmap, Sankey, timeline, C4, and 20+ other diagram types. Works natively in GitHub/GitLab, can be embedded in Markdown via `astro-mermaid`, and is framework-agnostic. Helps present material by turning human-readable text into publication-quality diagrams that render directly in documentation, wikis, and presentations. (MIT · library)
- [Excalidraw](https://github.com/excalidraw/excalidraw) — Virtual whiteboard for sketching hand-drawn-like diagrams with a beautiful, sketchy aesthetic. Exports as PNG/SVG/Excalidraw file, supports multiple collaborators in real time, and integrates well with Markdown docs. Helps present material by providing an approachable, informal diagram style that makes technical content feel accessible and conversational — ideal for architecture sketches, brainstorming sessions, and tutorial illustrations. (MIT · library)
- [tldraw](https://github.com/tldraw/tldraw) — React-based infinite canvas SDK for building custom diagramming and whiteboard apps. Provides a full drawing canvas with shapes, text, and tools — ideal for embedding interactive whiteboards in documentation sites, developer portals, or any app that needs collaborative visual diagramming. The SDK includes default whiteboarding tools but also lets you build entirely custom shapes and interactions. **Note: production use requires a license key** — see the tldraw license section below. (tldraw license · framework)
- [D2 (Diagram Language)](https://github.com/d2lang/d2) — Modern diagram scripting language that turns text to diagrams, designed as a cleaner alternative to Graphviz with more approachable syntax and faster rendering. Outputs PNG, SVG, PDF. Helps present material by letting developers write diagram descriptions alongside their code in the same repo, so diagrams stay in sync with the codebase and render consistently across all documentation and presentations. (Apache-2.0 · library)
- [PlantUML](https://github.com/plantuml/plantuml) — Java-based tool that generates UML diagrams from textual descriptions. Well-established (18+ years), supports class, sequence, component, state, activity, deployment, timing, use case, object, and architecture diagrams. Works with any text editor and integrates with CI/CD pipelines. Helps present material by generating professional UML diagrams from plain-text specifications that can be embedded in Markdown, Confluence, and technical documentation. ⚠️ Multi-licensed (LGPL-3.0, Apache, MIT, Eclipse Public) — the LGPL-3.0 variant has copyleft requirements for linking. (LGPL-3.0 / multi-licensed · library)
- [Rough.js](https://github.com/rough-stuff/rough) — JavaScript library that creates graphics with a hand-drawn, sketchy, appearance. SVG and Canvas backend. Used by Excalidraw and many other sketchy-diagram tools. Helps present material by allowing any existing chart or diagram library to get a hand-drawn aesthetic with a single wrapper — great for making technical diagrams feel more approachable, informal, and human. Very lightweight (~5KB gzipped) with no framework dependencies. (MIT · library)
- [bpmn-js](https://github.com/bpmn-io/bpmn-js) — A BPMN 2.0 rendering toolkit and web modeler. Allows embedding business process diagrams directly in web applications with full modeling, previewing, and export capabilities. Helps present material by making complex business workflows, process flows, and architecture diagrams interactive and editable in the browser — ideal for documentation sites that need to present business process information in an engaging, navigable way. (bpmn.io license · library)
- [AntV G6](https://github.com/antvis/G6) — Interactive graph visualization framework by Alibaba AntV. Supports force-directed, hierarchical, radial, and other layouts. Highly performant with WebGL renderer, handles large graphs efficiently. Helps present material by making network diagrams, knowledge graphs, and relationship visualisations interactive and performant — ideal for exploring complex data relationships in documentation, knowledge bases, and analytical dashboards. (MIT · library)
- [AntV G2](https://github.com/antvis/G2) — The concise and progressive visualization grammar by Alibaba AntV. A powerful charting grammar for building charts, dashboards, and data visualisations. Supports a wide range of chart types, custom themes, and interactions. Helps present material by providing a declarative grammar for chart design that makes it easy to create consistent, themed visualisations across an entire documentation or reporting system — ideal for teams that need a unified charting style guide. (MIT · library)
## Docs & Long-form Content Presentation

- [Starlight](https://github.com/withastro/starlight) — Full-featured docs theme for Astro with search, i18n, SEO, dark mode, and accessible navigation. Framework-agnostic; the natural home for Astro-based docs sites and directly compatible with the Crofter stack. (MIT · framework)
- [Nextra](https://github.com/shuding/nextra) — Next.js-based static site generator with Markdown/MDX, file-system routing, syntax highlighting, and custom layouts. Works with React and Tailwind. Great for content-rich sites beyond docs, with built-in MDX support for interactive content. (MIT · framework)
- [Docusaurus](https://github.com/facebook/docusaurus) — Meta's React-based documentation and marketing site generator with versioned docs, blog, search, i18n, and a plugin ecosystem. Mature ecosystem with strong React integration and a proven track record for large-scale docs. (MIT · framework)
- [VitePress](https://github.com/vuejs/vitepress) — Vue-powered static site generator built on Vite for blazing-fast documentation sites. Markdown-first with Vue components in Markdown, search, and theming. Built by Evan You; excellent for Vue projects while the Vite tooling is framework-agnostic. (MIT · framework)
- [MkDocs Material](https://github.com/squidfunk/mkdocs-material) — Material Design-themed static site generator for MkDocs (Python-based). Excellent typography, built-in search, i18n, and analytics. Not React-based but worth noting for non-JS stacks or when the content team prefers Python tooling. (MIT · framework)
- [Marp](https://github.com/marp-team/marp) — Markdown presentation framework with slide decks, PDF export, theme support, and reveal.js-based preview. CLI and VS Code extension. Good for internal technical presentations and team docs where you want slide content authored in Markdown. (MIT · tool)
- [Slidev](https://github.com/slidevjs/slidev) — Developer-focused slides created in Markdown with live browser preview, code highlighting, animations, and web-based sharing. Built on Vue with Vite-powered workflow. Excellent for conferences, demos, and technical talks with a polished developer aesthetic. (MIT · tool)
- [Slides](https://github.com/maaslalani/slides) — Terminal-based presentation tool that renders Markdown as slides in a live terminal preview. Minimal dependency, great for quick terminal presentations and demos where a browser isn't practical. (MIT · tool)
- [Framer Motion](https://github.com/framer/motion) — Production-grade motion library for React and JavaScript (now under motiondivision). Declarative animations, gesture handling, drag, layout transitions, and scroll-based effects. Excellent for polished, accessible UI motion that makes documentation and dashboard interfaces feel alive. (MIT · library)
- [Google Fonts](https://github.com/google/fonts) — Free, open-source font library with over 1500 font families including variable fonts, used via @fontsource for web deployment. Provides ready-to-use web fonts that serve as the typographic foundation for docs, dashboards, and presentation sites. ⚠️ Font files are subject to the Google Fonts Terms of Service, which restrict embedding in SaaS products or apps — use with caution in commercial products. (Apache-2.0 · assets)
- [Lucide](https://github.com/lucide-icons/lucide) — Beautiful, consistent open-source icons powering shadcn/ui. Tree-shakeable, accessible SVG icons with 2000+ icons across React, Vue, Svelte, and more. The ISC license makes it safe for commercial use. Essential for consistent iconography across documentation and dashboard interfaces. (ISC · assets)
- [Tabler Icons](https://github.com/tabler/tabler-icons) — 6100+ free, MIT-licensed high-quality SVG icons with 25 styles (outline, duotone, bold, etc.). Available for React, Vue, Svelte, and more. Good complement or alternative to lucide-react when you need a larger icon set with more stylistic variety. (MIT · assets)

- [Lucide](https://lucide.dev) — Beautiful, consistent open-source icon toolkit made by the community. Fork of Feather Icons with 1,776+ icons available as React, Vue, Svelte, and SVG components. Lightweight, highly optimized SVG. (ISC · library)
- [Heroicons](https://heroicons.com) — Free, high-quality SVG icons from the creators of Tailwind CSS. Available in Outline, Solid, Mini, and Micro variants with React components (@heroicons/react). Widely used with shadcn/ui and Tailwind v4 stacks. (MIT · library)

- [Iconify](https://iconify.design) — Universal icon framework providing access to 200+ icon sets (Font Awesome, Material Design, Feather, Noto Emoji, and 150+ more) via a unified API. ~300,000 open-source vector icons. - [Octicons](https://github.com/primer/octicons) — Scalable set of SVG icons handcrafted by GitHub for GitHub. @primer/octicons-react provides React components. MIT licensed. Includes 200+ icons covering git, UI, social, and action categories. Excellent for developer-facing interfaces. (MIT · library)
- [Font Awesome](https://fontawesome.com) — The internet's most popular icon library and toolkit. Version 7 offers a redesigned icon set with 19,000+ icons. MIT license for most features; some commercial plugins require Business Green license. (MIT · library)
- [Tailwind Colors](https://tailwindcss.com/docs/customizing-colors) — Tailwind CSS v4's built-in color palette with 12 hue scales. Customizable via CSS variables and theme configuration. Supports oklch() color space natively in v4. The standard color system for Tailwind-based stacks. (MIT · library)
